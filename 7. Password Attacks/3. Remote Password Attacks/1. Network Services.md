### WinRM
- The Microsoft implementation of the **Web Services Management Protocol (WS-Management)** 
- Its a network protocol based on XML web services using the **Simple Object Access Protocol (SOAP)** used for remote management of Windows system
- It takes care of the communication between **Web-Based Enterprise Management (WBEM)** and the **Windows Management Instrumentation (WMI)**, which can call the **Distributed Component Object Model (DCOM)**
- WinRM must be activated and configured manually in Windows 10/11
- Mostly, it uses certificates or only specific authentication mechanisms to increase its security
- TCP port: 5985 (HTTP) and 5986 (HTTPS)
- We can use **NetExec** for our password attacks, which can also be used for other protocols such as SMB, LDAP, MSSQL, and others, or we can use **Evil-WinRM**

****
### NetExec
**Installing NetExec**
- `nix-shell -p netexec`

**NetExec Menu Options**
- `netexec -h`

**NetExec Protocol-Specific Help**
- We can specify a specific protocol and receive a more detailed help menu of all of the options available to us
- `netexec [protocol name] -h`

**NetExec Usage**
- `netexec [protocol] [target IP] -u [user or userlist] -p [password or passwordlist]`

### SSH (Secure Shell) — Port 22
- Three crypto methods: **symmetric (AES, Blowfish)**, **asymmetric (public/private key)**, **hashing**
- **Brute force:** `hydra -L user.list -P password.list ssh://[target]`
- **Connect:** `ssh user@[target]`

****
### RDP (Remote Desktop Protocol) — Port 3389
- Windows remote access protocol (TCP/UDP)
- **Allows:** remote desktop control, file transfer, printer sharing
- **Brute force:** `hydra -L user.list -P password.list rdp://[target]`
- **Connect:** `xfreerdp /v:[target] /u:[username] /p:[password]`
- **Warning:** RDP doesn't like many parallel connections (-t 1 or -t 4 recommended)

****
### SMB (Server Message Block) — Port 445
- File sharing protocol for Windows networks
- Also called **CIFS (Common Internet File System)**
- Samba = open-source SMB implementation
- **Brute force:** `hydra -L user.list -P password.list smb://[target]`
- Or: `MSF module auxiliary/scanner/smb/smb_login`

**MSF SMB Brute Force:**
- `use auxiliary/scanner/smb/smb_login`
- `set user_file [file]`
- `set pass_file [file]`
- `set rhosts [target]`
- `run`

**After Successful SMB Login:**
- **NetExec**: `netexec smb [target] -u "[user]" -p "[pass]" --shares (view shares + permissions)``
- **Smbclient:** `smbclient -U [user] \\\\[target]\\[share] (interactive SMB shell)`
  - `ls`, `cd`, `get`, `put`, etc.

****
### Key Concept:
- All three protocols used for remote access + lateral movement
- Brute force same approach for all (Hydra/MSF)
- Once authenticated, enumerate what's available (shares, files, permissions)
