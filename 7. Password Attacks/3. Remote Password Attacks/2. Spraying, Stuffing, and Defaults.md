### Password Spraying
- A brute-force attack where a single password is attempted to be used across many different user accounts
- Effective where new users have a default password
- For active directory: **NetExec** or **Kerbrute** are used
- `netexec [service] [target IP range like 10.10.10.10/24] -u [username list] -p'[password]'`

****
### Credential Stuffing
- A brute-force attack where stolen credentials from one service are used to access others
- Effective when users use same password across different services
- `hydra -C user_pass.list [service]://[target IP]`

****
### Default Credentials
- Many systems come with default credentials
- Sometimes, these aren't changed so are vulnerable
- **Default Credentials Cheat Sheet** is a default credentials list available online
- `pip3 install defaultcreds-cheat-sheet`
- `creds`: Command to search for known default credentials of a vendor or product
	- `creds search linksys(vendor or product)`
