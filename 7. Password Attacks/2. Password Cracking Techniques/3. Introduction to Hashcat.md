- A well-known password cracking tool
- Features GPU support
- `hashcat -a [attack mode] -m [hash type] [hashes] [wordlist, rule, mask, ...]`

****
### Hash Types
- A list of associated IDs can be generated by running `hashcat --help`
- `hashid -m '[hash text]'`: To identify hash type

****
### Attack Modes
1. **Dictionary Attack**
	- `-a 0`
	- Uses a wordlist
	- `hashcat -a 0 -m [hash format] [hash text] [wordlist]`
	- Sometimes, wordlist alone is not enough to crack a password hash. so rules can be used to perform specific modifications to passwords to generate even more guesses
	- `ls -l /usr/share/hashcat/rules`, but different path in NixOS
	- `hashcat -a 0 -m [hash format] [wordlist] -r [rules]`
2. **Mask Attack**
	- `-a 3`
	- A type of brute-force attack in which the keyspace is explicitly defined by the user
	- Custom charsets can be defined with the `-1`, `-2`, `-3`, and `-4` arguments, then referred to with `?1`, `?2`, `?3`, and `?4`

| Symbol | Charset                             |
| ------ | ----------------------------------- |
| ?l     | abcdefghijklmnopqrstuvwxyz          |
| ?u     | ABCDEFGHIJKLMNOPQRSTUVWXYZ          |
| ?d     | 0123456789                          |
| ?h     | 0123456789abcdef                    |
| ?H     | 0123456789ABCDEF                    |
| ?s     | «space»!"#$%&'()*+,-./:;<=>?@[]^_`{ |
| ?a     | ?l?u?d?s                            |
| ?b     | 0x00 - 0xff                         |
