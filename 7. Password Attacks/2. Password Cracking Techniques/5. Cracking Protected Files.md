- **Symmetric encryption** alogorithms such as **AES-256** are used to securely store individual files and folders, in which the same key is used for both encryption and decryption
- **Asymmetric encryption** is used for transmitting files which uses two distinct keys: the sender encrypts the file with the recipient's **public key**, and the recipient decrypts it using the corresponding **private key**

****
### Hunting for Encrypted Files
- To locate commonly encrypted files: `for ext in $(echo ".xls .xls* .xltx .od* .doc .doc* .pdf .pot .pot* .pp*"); do echo -e "\nFile extension: " $ext; find / -name *$ext 2>/dev/null | grep -v "lib\|fonts\|share\|core" ;done`

****
### Hunting for SSH Keys
- Certain files, such as SSH keys, do not have standard file extension
- These files can be identified by standard content such as header and footer values
- `grep -rnE '^\-{5}BEGIN [A-Z0-9]+ PRIVATE KEY\-{5}$' /* 2>/dev/null`
- One way to tell whether an SSH key is encrypted or not, is to try reading the key with `ssh-keygen`
	- `ssh-keygen -yf ~/.ssh/[ssh files]`

****
### Cracking Encrypted SSH Keys
- `ssh2john.py [ssh file] > [output hash file]`
- `john --wordlist=[wordlist] [hash file]`
- `john [hash file] --show`

****
### Cracking Password-Protected Documents
**1) Office File**
- `office2john.py [protected file] > [hash file]`
- `john --wordlist=rockyou.txt [hash file]`
- `john [hash file] --show`
**2) PDF File**
- `pdf2john.py [protected file] > [hash file]`
- `john --wordlist=rockyou.txt [hash file]`
- `john [hash file] --show`
