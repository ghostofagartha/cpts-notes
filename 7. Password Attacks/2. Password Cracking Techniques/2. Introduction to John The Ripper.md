- Used for cracking passwords through various attacks including brute-force and dictionary

****
### Cracking Modes
1. **Single Crack Mode**
	- A rule-based cracking technique that is most useful when targeting Linux credentials
	- It generates passwords candidates based on the victim's username, home directory name, and **GECOS** values (full name, room number, phone number etc.)
	- `john --single [password/hash file]`
2. **Wordlist Mode**
	- Used to crack passwords with a dictionary attack, meaning it attempts all passwords in a supplied wordlist against the password hash
	- `john --wordlist=[wordlist file] [hash file]`
	- Rules can be specified by using the `--rules` argument
3. **Incremental Mode**
	- Is a powerful, brute-force-style password cracking mode that generates candidate passwords based on a statistical model (Markov Chains)
	- Designed to test all character combinations defined by a specific character set, prioritizing more likely passwords based on training data
	- Most exhaustive, and most time-consuming
	- `john --incremental [hash file]`
	- By default, **John The Ripper** uses predefined incremental modes specified in its configuration file: `john.conf`, which defines character sets and password lengths. These are customizable

****
### Identifying Hash Formats
- You can get idea is from **JtR's sample hash documentation**, or **this list by PentestMonkey**
- You can use **hashID**, or more reliably, **name-that-hash** too
- `hashid -j [hash text]`
- `nth --text '[hash text]'`, or `nth --file [hash file]`
- `john --format=[hash format] [hash file]`

### Cracking Files
- It is possible to crack password-protected or encrypted files with JtR
- Multiple **"2john"** tools come with JtR
- **Syntax for The Tools**: `[tool] [file to crack] > file.hash`
