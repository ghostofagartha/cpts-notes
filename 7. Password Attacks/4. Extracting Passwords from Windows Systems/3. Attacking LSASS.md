- **LSASS**: Local Security Authority Subsystem Service is a core Windows process responsible for enforcing security policies, handling user authentication, and storing sensitive credential material in memory
![[Pasted image 20260810184154.png]]
- Upon initial login, LSASS will:
	- Cache credentials locally in memory
	- Create access tokens
	- Enforce security policies
	- Write to Windows' security log

****
### Dumping LSASS Process Memory
- We should create a copy of the contents of LSASS process memory via the generation of a memory dump
- Creating a dump file lets us extract credentials offline using out attack host
- We can create a memory dump in many ways:

1. **Task Manager Method**
	1. Open `Task Manager`
	2. Select the `Processes` tab
	3. Find and right click the `Local Security Authority Process`
	4. Select `Create dump file`
	- A file called `lsass.DMP` and saved in `%tmp%`
2. **Rundll32.exe & Comsvcs.dll Method**
	- We can't ise Task Manager Method if we dont have GUI session
	- Modern anti-virus tools recognize this method as malicious activity
	- Before creating the dump file, we must know the **PID** assigned to `lsass.exe`
	- **Finding LSASS's PID in cmd**: `tasklist /svc`
	- **Finding LSASS's PID in cmd**: `Get-Process lsass`
	1. **Creating a Dump File using PowerShell**
		- `rundll32 C:\windows\system32\comsvcs.dll, MiniDump [lsass PID] C:\lsass.dmp full`

****
### Using Pypykatz to Extract Credentials
- `pypykatz`: A tool to extract credentials from `.dmp` file

**Running Pypykatz**
- `pypykatz lsa minidump [lsass.dmp file location]`
- **Output Parts**
	1. **MSV**
		- An authentication package in Windows that LSA calls to validate logon attempts against SAM database
	2. **WDIGEST**
		- An older authentication protocol enabled by default in Windows XP - Windows 8 and Windows 2003 - Windows 2012
	3. **Kerberos**
		- A network authentication protocol used by Active Directory in Windows Domain environments
		- Domain user accounts are granted tickets upon authentication with Active Directory
	4. **DPAPI**
		- Mimikatz and Pypykatz can extract DPAPI **masterkey** for logged-on users whose data is present in LSASS process memory
		- These masterkeys can then be used to decrypt secrets associated with each of the applications using DPAPI
