### ASPX
- **Active Server Page Extended (ASPX)**
- A file type/extension written for **Microsoft ASP.NET Framework**
- We can use aspx to control the underlying Windows OS

****
### Antak Webshell
- A web shell built in ASP.NET included within the **Nishang Project**
- **Nishang** is an Offensive PowerShell toolset that can provide options for any portion of your pentest
- Antak utilizes PowerShell to interact with the host, making it great for acquiring a web shell on a Windows server

****
### Working with Antak
- Antak files are located at `/usr/share/nishang/Antak-WebShell`
- Antak web shell functions like a PowerShell Console
- It executes each command as a new process
- Can execute scripts in memory and encode commands you send
