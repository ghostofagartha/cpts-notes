### Metasploit
- Automated framework developed by **Rapid7**
- Streamlines the process of exploiting vulnerabilities through the use of pre-built modules that contain easy-to-use options to exploit vulnerabilities and deliver payloads to gain a shell on a vulnerable system

### Using Metasploit
1. **Starting Metasploit**
	- `sudo msfconsole`
2. **Searching for Exploit in Metasploit**
	- `search [service name or exploit name]`
3. **Exploits Format when Searching**
	- `56`: Number assigned to the exploit
	- `exploit/`: Type of module
	- `windows/`: Target platform
	- `smb/`: Target service
	- `psexec/`: Tools that will get uploaded to the target system if it is vulnerable
4. **Showing Options**
	- `show options`
5. **Option Selection**
	- `use [exploit number]`
6. **Setting Options**
	- `set [parameter] [new value]`
7. **Running the Exploit**
	- `exploit`
8. **Interactive Shell**
	- `shell`
