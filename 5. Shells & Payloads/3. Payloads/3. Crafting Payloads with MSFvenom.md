- **MSFvenom** is used to craft a payload, so that we could send the payload to a remote device that is not on our local network, via email or other means social engineering
- MSFvenom also allows us to **encrypt** & **decode** payloads to bypass common anti-virus detection signature

### Practicing with MSFvenom
1. **List Payloads**
	- `msfvenom -l payloads`

****
### Staged vs. Stageless Payloads
- **Staged**: Create a way for us to send over more components of our attack
	- When run using an exploit module in Metasploit, it sends small **stage** that will be executed on the target and then call back to the personal machine to download remainder of the payload
	- More traffic
- **Stageless**: Do not have a stage
	- When run using an exploit module in Metasploit, this payload will be sent in its entirety across a network connection without a stage
	- Less traffic

****
### Building A Stageless Payload
- `msfvenom -p [full payload name] [option]=[value] -f elf(payload format) > [output file name]`
