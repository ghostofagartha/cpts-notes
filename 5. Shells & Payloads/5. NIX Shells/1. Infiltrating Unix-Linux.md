### Common Considerations
We should consider following before considering how we will establish a shell session on Unix/Linux system
- What distribution of Linux is the system running?
- What shell and programming languages exist on the system?
- What function is the system serving for the network environment it is on?
- Are there any known vulnerabilities?

### Gaining a Shell Through Attacking a Vulnerable Application
1. **Enumerate the Host**
	- `nmap -sC -sV [ip address]`
2. **Explore the Services to Attack**
3. **Search For an Exploit Module**
	- `search [service]`
	- There may be useful exploit modules that are not installed on our system or just aren't showing up via search
	- Its good to know that Rapid 7 keeps code for exploit modules on there repos on github: https://github.com/rapid7/metasploit-framework/tree/master/modules/exploits
	- Choose an exploit from repos directly and download it to the path where Metasploit keeps its exploits, use `locate exploits`
4. **Select an Exploit**
	- `use [exploit number or exploit full name]`
5. **Set Options**
6. **Using the Exploit and Gaining a Shell**
	- `exploit`
7. **Interact With the Shell**
	- `shell`
