- Ruby-based, modular penetration testing platform that enables you to write, test, and execute the exploit code
- **Modules** are actual exploit proof-of-concepts that have already been developed and tested

### Metasploit Framework Console
- `msfconsole`
- Provides an "all in one" centralized console and allows you efficient access to virtually all options available in the **MSF**
- **Features**
	- The only supported way to access most of the features withing Metasploit
	- Provides console-based interface to Metasploit
	- Contains the most features and is the most stable MSF interface
	- Full readline support, tabbing, and command completion
	- Execution of external commands in **msfconsole**

****
### Understanding the Architecture
- All base files can be found under `/usr/share/metasploit-framework` in **Parrot Security** distro, and under `/opt/metasploit` in **Arch** distro
1. **Data, Documentation, Lib**
	- Base files for the Framework
	- Data and Lib are the functioning part of the msfconsole interface, while the Documentation folder contains all the technical details about the project
2. **Modules**
	- The modules detailed earlier are split into separate categories in this folder
3. **Plugins**
	- Plugins offer pentester more flexibility when using **msfconsole** since they can easily be manually or automatically loaded as needed
4. **Scripts**
	- Meterpreter functionality and other useful scripts
5. **Tools**
	- Command-line utilities that can be called directly from the **msfconsole** menu
