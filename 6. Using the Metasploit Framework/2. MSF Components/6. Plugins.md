### Using Plugins
- `/opt/metasploit/plugins`

****
### MSF - Load Plugins
- `load [plugin name]`

****
### Installing new Plugins
**Downloading MSF Plugins**
- `git clone https://github.com/darkoperator/Metasploit-Plugins`
- `ls Metasploit-Plugins`
**MSF - Copying Plugins to MSF**
- `sudo cp ./Metasploit-Plugins/[plugin file] /opt/metasploit/plugins/`
**MSF - Load Plugins**
- `load [plugin name without file extension]`

### Mixins
- Metasploit Framework is written in Ruby, an object-oriented programming language.
- Mixins are classes that act as methods for use by other classes without having to be the parent class of those other classes. Mainly uses when we:
	1. Want to provide a lot of optional features for a class
	2. Want to use one particular feature for a multitude of classes
