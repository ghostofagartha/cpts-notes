### Setup:
- `sudo systemctl start postgresql`
- `sudo msfdb init` (or `reinit` if issues)
- `sudo msfdb run` (start msfconsole with DB connected)
- `db_status` (verify connection)

****
### Workspaces (organize by target):
- `workspace` (list)
- `workspace -a [name]` (add)
- `workspace [name]` (switch)
- `workspace -d [name]` (delete)

****
### Import/Export:
- `db_import [file.xml]` (import Nmap scans)
- `db_nmap -sV -sS [target]` (run Nmap from MSF, auto-import)
- `db_export -f xml [filename]` (backup)

****
### View Data:
- `hosts` (list discovered hosts)
- `services` (list discovered services)
- `creds` (list captured credentials)
- `loot` (list dumped hashes, passwd files, etc.)

****
### Key Concept:
- Database tracks scan results, credentials, loot across engagements
- Workspaces isolate different assessments
- Auto-populated from Nmap, Nessus, manual entry
