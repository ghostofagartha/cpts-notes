- **Targets** are unique operating system identifiers taken from the versions of those specific operating system which adapt the selected exploit module to run on that particular version of the operating system

**MSF - Show Targets**
- `show targets`

**MSF - Target Selection**
- `set target [index number]`, after selecting an exploit module and running `show targets`
- `info`: For exploit module info
- `options`:  For all the options
