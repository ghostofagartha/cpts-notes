### Importing Existing Modules:
- Search ExploitDB: `searchsploit [exploit_name]`
- Filter for .rb files (Metasploit-compatible)
- Download .rb file
- Copy to: `/usr/share/metasploit-framework/modules/exploits/[category]/filename.rb`
- Naming: snake_case only (nagios3_command_injection.rb, not nagios3-command-injection.rb)
- Reload in msfconsole: `reload_all` or `loadpath /usr/share/metasploit-framework/modules/`
- Use: `use exploit/[path]/[name]`

### Writing Custom Ruby Modules (Advanced):
- Requires Ruby knowledge
- Use existing modules as boilerplate
- Key sections: metadata (Name, Description, Author, CVE, References), options (register_options), exploit code
- Mixins: HttpClient, PhpEXE, FileDropper, Report (provides functionality)
- Reference Metasploit documentation for correct syntax
- Use hard tabs in Ruby code
