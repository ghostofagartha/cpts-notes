### Defense Layers:
- Endpoint Protection: Local AV, Antimalware, Firewall (on each host)
- Perimeter Protection: Network firewalls, IDS/IPS (on network edge)
- DMZ: Lower security zone for public-facing servers
- SOC: Live analysts monitoring alerts (human element, unpredictable)

****
### Detection Methods:
- Signature-based: Matches known attack patterns (outdated, easily bypassed)
- Heuristic/Anomaly: Detects behavioral deviation from baseline
- Stateful Protocol Analysis: Recognizes protocol violations
- Live SOC monitoring: Human analysts

****
### AV Evasion Techniques
1. **Encoded Payloads (Limited effectiveness)**
	- msfvenom with -e encoder and -i iterations
	- Modern AV uses heuristics, not just signatures (encoding alone fails)

2. **Executable Templates**
	- `msfvenom -p [payload] -x [legitimate.exe] -k -o output.exe`
	- -x = inject payload into legitimate executable (hides payload in legit code)
	- -k = keep legitimate program running after payload executes
	- Example: embed payload in TeamViewer installer

3. **Archiving + Password**
	- Create .rar archive with password: rar a payload.rar -p payload.exe
	- Remove .rar extension: mv payload.rar payload
	- Archive again with password, remove extension again
	- Result: AV can't scan (password-protected), file type unknown
	- Test: 0/49 AV engines detected double-archived payload

1. **Packers**
	- Compresses/encrypts executable structure (UPX, Themida, MPRESS, etc.)
	- Decompresses transparently at runtime

1. **AES Encryption**
	- Meterpreter can tunnel encrypted traffic (defeats network IDS/IPS)

1. **Exploit Code Randomization**
	- Randomize buffer offsets, NOP sleds in exploit code
	- Breaks IDS/IPS database signatures for known exploits
